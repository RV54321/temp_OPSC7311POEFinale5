Steps to using the Application:
 1)Open the application on your phone (not an emulator).

 2)The first page is the 'Login Page'.
   You can enter your Email and Password to proceed.

 3)If you do not have an account set up:
   You can press the 'Register' Button to move to the Register Page to set one up.
   The 'Register' Page will ask for your Name, Email and Password.

 4)You will see the category page, where you can select:
   *CREATE CATEGORY
   *CREATE TIMESHEET
   *CREATE TIMESHEET LIST
   *CREATE TEAM
   *USE CALENDER

  4.1)CREATE CATEGORY: 
      You can enter in the Category 'Name', then select 'ADD CATEGORY' to create it.
      You can use the 'Return' Button to head back to the main page.
  4.2)CREATE TIMESHEET: 
      You can enter in:
       -Date
       -Start times
       -End Times
       -Description
       -Category (carries over from the previous page)
       -Add photograph (optional)
       -Minimum daily goal
       -Maximum daily goal
      Then select 'CREATE' to create that Timesheet.
      You can use the 'Return' Button to head back to the main page.
  4.3)VIEW TIMESHEET LIST:
      You can enter in:
       -Start Date
       -End Date
      then select 'SUBMIT', this will cuase a lit to pop up showing the Timesheet list.
      You can use the 'Return' Button to head back to the main page.
  4.4)CREATE TEAMS: 
      Allows you to create a Team with members assigned to a specific category.
      You can use the 'Return' Button to head back to the main page.
  4.5)USE CALENDER: 
      Allows you to use basic calender functions.
      You can use the 'Return' Button to head back to the main page.
      

 5)You can close the applciation by exiting it or by pressing the 'LOGOUT' button.
